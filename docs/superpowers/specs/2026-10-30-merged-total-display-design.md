# 合并总流量展示与告警口径提示 — 设计文档

日期：2026-10-30
状态：已定稿（用户已批准；视觉方案经浏览器 mockup 对比选定）

## 背景与目标

流量告警的口径是「所有模块累计上行 + 下行的合并流量」（`TrafficAlert` 基于 `currentMeteredTotal()` = Wi-Fi + iPhone 的 rx+tx 之和），但展示层没有体现这一口径：

1. 主页没有突出的合并总流量展示；
2. 告警设置入口只说「总流量」，未点明合并口径；
3. 状态栏菜单的 Wi-Fi / iPhone 行混排实时速率与累计，重点不清。

本次改动**全部在展示层**：告警算法、基线/重置联动、通知逻辑一律不动。

## ① 主页布局（方案 B：右侧圆环仪表）

窗口从 720×428 加高到约 720×470，其余区域结构如下：

- **左列**（上下堆叠）：
  - 汇总条：只留「会话 | 总上传 | 总下载」；「流量告警」项从汇总条移除（转入圆环面板）。
  - Wi-Fi 卡、iPhone 卡：加宽堆叠。每卡两行——上行「● 名称 · 接口 | 开始时间 · 已运行 | 重置按钮」，下行「↓ 速率 ↑ 速率 | 累计 ↑ x ↓ y」。运行/未启用逻辑、独立计时与重置行为不变。
- **右列：合并总流量圆环面板**（与左列等高）：
  - `RingGaugeView` 自绘圆环：轨道环常驻；告警进度弧 = 已用/阈值（钳位 0…1）。
  - 环心：**全局合并总流量**大号等宽数字（= 所有模块累计上行 + 下行之和，与告警口径同一个数；区别于 ② 中菜单行各自的合并值）。
  - 环下：小字「合并总流量」+ 告警状态文字（复用现有 `alertStrip` 纯函数的文案与状态）。
  - 三态：**未设置** = 灰色素环（无弧）+ 白色数字 + 「告警未设置」；**进行中** = 橙色弧 + 橙色状态字；**已触发** = 整环红 + 「已触发」。
- 底部速率图、图例行、版本号、软件更新卡片（展开/收起平移）逻辑全部不动；左列与圆环面板均纳入 `updateBaseViews` 参与整体平移。

视觉方案备选记录（含 A 汇总条升级 / C 第三张卡）见 `.superpowers/brainstorm/` 下 mockup 存档。

## ② 状态栏菜单 Wi-Fi / iPhone 行

现状：`名称 | ↑累计 ↓累计 | 实时速率`。改为：

```
Wi-Fi      ↑ 1.1 GB  ↓ 4.2 GB    5.3 GB
```

- 删除实时速率列；新增第三列 = **该行自己的合并值**（上行 + 下行），semibold 加粗、无箭头，与累计列区分。
- 彩色箭头、等宽数字风格沿用 `MenuTextBuilder` 现有样式，tab 位重排。
- 状态栏顶栏（`StatusBarFormatter`）的速率/累计显示**不受影响**（那是主页顶部两个开关控制的独立偏好）。

## ③ 告警口径提示文案

- 告警子菜单顶部说明：「总流量达到阈值时提醒一次」→ **「按所有模块累计上行 + 下行的合并流量提醒一次」**。
- 自定义阈值弹窗说明改为：**「输入达到时提醒的合并流量（所有模块累计上行 + 下行）。示例：5 GB、500 MB。设置后进度重新计算，已触发的提醒状态会被清除。」**
- 告警触发通知正文、菜单「● 流量告警 · 剩 x · 已用 y%」header 文案不变。

## 架构与数据流

- 新增 `RingGaugeView`（`NSView` 子类，`draw(_:)` 自绘，与 `RateGraphView` 同模式）：输入弧比例与状态，只负责绘制；不做点击交互。
- 新增纯函数计算弧比例（threshold 为 nil → 不画弧；比例钳位 0…1；fired → 1），进内置 SelfTest。
- `HomePageController` 重排 `buildUI()`：左列/右列容器、卡片双行布局、环面板；`alertValueLabel` 由环面板状态 label 取代。
- 数据流不变：每秒 tick → observer → refresh（环与曲线同频重绘）。

## 明确不做

告警算法与阈值预设变更、每接口各自的圆环、主页卡片删实时速率（仅菜单删）、状态栏顶栏展示变更、历史持久化。

## 测试

- `MenuTextBuilderTests`：更新接口行用例（无速率列、含合并列、tab 对齐）。
- 新增弧比例纯函数用例：未设置（nil）、进行中（钳位）、已触发（= 1）。
- `TrafficAlertTests`、`alertStrip` 相关用例不动。
- 45 项自测命令保持全绿，新增用例并入 SelfTest 套件；UI 运行验证沿用现有方式（启动后目测主页与菜单）。
