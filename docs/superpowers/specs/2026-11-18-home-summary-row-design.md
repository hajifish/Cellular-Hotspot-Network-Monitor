# 主页左列重排：汇总条上移同行 + 总流量汇总项

日期：2026-11-18 ｜ 分支：`feature/home-summary-row` ｜ 状态：已确认（用户选定"卡片加高填满"方案）

## 需求

1. 左列汇总条（会话 / 总上传 / 总下载）上移到右上角「累计流量」开关胶囊同一行（顶边对齐）。
2. 汇总条新增第四项「总流量」= 总上传 + 总下载，放在总下载右侧。
3. 右列告警圆环面板保持不动。
4. 左列接口卡片加高填满汇总条上移后空出的空间，左右列上下边缘对齐。

## 布局几何（AppKit 底左原点，窗口 720×470）

| 元素 | 改动前 | 改动后 |
|---|---|---|
| 汇总条 | (24, 368, 456, 46) | (24, **402**, 456, 46)，顶边 448 = 开关胶囊顶边 |
| 汇总槽位 x | 会话18 / 总上传150 / 总下载280 | 会话18 / 总上传126 / 总下载234 / **总流量342**，各宽 105 |
| Wi-Fi / iPhone 卡 | (24/259, 180, 221, 182) | (24/259, 180, 221, **214**)，顶边 394 |
| 卡内 title/meta/reset | local y 150/134/148 | **+32** → 182/166/180（随顶边上移） |
| 卡内 rate/total | local y 58/20 | 不变（贴底） |
| 圆环面板 | (492, 180, 204, 234) | 不动 |

- 左列：汇总条 402–448 + 8pt 间隔 + 卡片 180–394；右列：开关 422–448 + 8pt 间隔 + 圆环 180–414。两列顶 448 / 底 180 一致。
- 汇总条宽 456 不变（4×105 槽位内放得下现有最长值），不与右列（x≥492）冲突。

## 总流量显示

新增纯函数 `HomePageController.summaryTotalLine(tx:rx:) -> String`，与既有 `totalLine` 风格一致：

```swift
nonisolated static func summaryTotalLine(tx: UInt64, rx: UInt64) -> String {
    "↑↓ \(ByteFormat.string(tx + rx))"
}
```

`refresh()` 中 `summaryValues[3].stringValue = Self.summaryTotalLine(tx: totalTX, rx: totalRX)`。

## 兼容性

- 窗口尺寸不变；图表折叠/展开（±126）与更新卡片展开（±84）的 `updateBaseViews` y 增量平移逻辑天然兼容新布局。
- 装机版应用不受影响（目检跑产物二进制，不 kill 装机版）。
